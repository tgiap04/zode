## Highlights

- Zode connects to the databases a project's `.idea` folder already names.
- RAM and CPU are measured for WSL and SSH projects on their own host.
- Run an agent session without permission prompts.

## Highlights (vi)

- Zode tự kết nối tới các cơ sở dữ liệu đã khai báo trong thư mục `.idea` của dự án.
- RAM và CPU của dự án WSL hay SSH được đo ngay trên máy chủ của chúng.
- Chạy phiên agent mà không phải trả lời từng lời hỏi quyền.

## Changes

### New

- Database connections read from a project's `.idea`.
- Project footprint for WSL and SSH projects.
- Run an agent session without permission prompts; a deleted session's tabs close.

### Improved

- The tab busy bar sweeps left to right.

### Fixed

- The commit graph scrolls sideways instead of drawing lanes over commit subjects.
- Terminal scrolling no longer marks an agent as busy.
- Remote clients receive the branch list.
- WSL folders open through the WSL connection on Windows.
