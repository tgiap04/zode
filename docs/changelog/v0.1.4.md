## Highlights

- Sync `.env` files between your machines, end-to-end encrypted, from a vault in the editor.
- Native notifications when an agent finishes, on macOS, Windows and Linux.
- Completions preview as inline ghost text, and projects get their own logos on the rail.

## Highlights (vi)

- Đồng bộ file `.env` giữa các máy, mã hóa đầu cuối, qua một kho ngay trong editor.
- Thông báo của hệ điều hành khi agent làm xong, trên macOS, Windows và Linux.
- Gợi ý code hiện mờ ngay trong dòng, và mỗi dự án có logo riêng trên thanh bên.

## Changes

### New

- End-to-end encrypted `.env` sync: send, fetch, rename and compare files from the vault, or from a right-click in the project panel.
- Native agent notifications on macOS, Windows and Linux.
- Keep the display awake while a terminal or subagent is working.
- Inline ghost text for the selected completion.
- Project logos on the rail and in menus.
- Open a terminal in any checkout from its card.
- Choose a kubeconfig in the container panel.

### Improved

- Dock and panel sizes are remembered per project.
- Agent sessions are titled by what was said in them.
- The brand colour runs through the chrome components.

### Fixed

- Going offline no longer signs you out.
- Container terminal buttons no longer close the app.
- Check for Updates moved into the application menu.
