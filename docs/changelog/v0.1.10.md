## Highlights

- A Devices panel boots iOS simulators and Android emulators and runs your app on them, without leaving the editor.
- Pair a phone with Zode by scanning a QR code.
- Issues and pull requests in a GitHub tab next to your code.
- Wellness reminders: a focus timer, water, eye breaks and standing up, from a menu bar panel.

## Highlights (vi)

- Panel Devices bật simulator iOS, emulator Android và chạy app của bạn trên đó, không cần rời editor.
- Ghép đôi điện thoại với Zode chỉ bằng cách quét mã QR.
- Tab GitHub hiện issue và pull request ngay cạnh code.
- Nhắc nhở sức khỏe: đồng hồ tập trung, uống nước, nghỉ mắt, đứng dậy, ngay trên thanh menu.

## Changes

### New

- Devices panel in the right dock: discover simulators, emulators and connected devices, and run the app.
- Pair a phone by scanning a QR code.
- GitHub tab for the repository's issues, pull requests and projects.
- Translate a selection.
- Push notifications to paired browsers when an agent needs you.
- Unlimited remote relay on paid plans.
- Focus timer and reminders in a menu bar panel.
- SF Mono and SF Pro are the default fonts on macOS.

### Fixed

- A tool's own error is kept when its input closes early.
- Push notifications are no longer refused on plans that include them.
- Release builds for macOS are signed and notarized.
