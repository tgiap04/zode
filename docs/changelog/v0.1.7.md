## Highlights

- Agents, databases and `.env` sync work on WSL and SSH projects, running on the project's own host.
- The interface icons are redrawn, and the window can be translucent, with vibrancy or a background image.
- Your plan shows in the status bar, and secrets can be shared with a team.

## Highlights (vi)

- Agent, cơ sở dữ liệu và đồng bộ `.env` chạy được với dự án WSL và SSH, ngay trên máy chủ của dự án.
- Bộ icon được vẽ lại, cửa sổ có thể trong suốt, có hiệu ứng vibrancy hoặc ảnh nền.
- Gói tài khoản hiện trên thanh trạng thái, và bạn có thể chia sẻ thông tin bí mật với nhóm.

## Changes

### New

- Launch, resume, fork and track agent sessions on a remote project's host.
- Database drivers install and run on a remote project's host; `.env` sync works there too.
- Remote control lists and resumes sessions on every open remote host.
- Interface icons redrawn with Phosphor.
- Window opacity, vibrancy and a background image.
- A usage bar beside each quota window in the status bar.
- Database: delete connections, view a row in full, import a URL into a connection form.
- The account plan as a tag in the status bar; plan limits explained; Team plan offered to people not in a team.
- Markdown preview opens in place of the editor tab and toggles back.
- The title bar can span the whole window.

### Improved

- Remote connections name the WSL distro and each step while connecting.
- Open and Running badges on agent sessions in the branch panel.

### Fixed

- Codex threads whose files were deleted no longer appear in the session list.
- The session history panel no longer crashes in remote windows.
- One file watch per path, with less watcher noise.
