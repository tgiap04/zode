## Highlights

- The Docker panel can inspect containers, show live stats and manage compose projects and resources.
- Edit database cells inline, with a first set of database tools.
- A Claude session resumes in the permission mode it was left in.

## Highlights (vi)

- Panel Docker xem chi tiết container, theo dõi tài nguyên trực tiếp, quản lý compose và các tài nguyên khác.
- Sửa ô dữ liệu ngay trong bảng, kèm bộ công cụ cơ sở dữ liệu đầu tiên.
- Phiên Claude mở lại đúng chế độ quyền như lúc bạn rời đi.

## Changes

### New

- Docker panel: inspect, stats, compose and resource management.
- Database: inline cell editing and tier-1 database tools.
- The window's vibrancy opacity is a setting.

### Improved

- Claude sessions resume in their previous permission mode.

### Fixed

- The container panel says when remotes could not be read, instead of saying there are none.
- A failed terminal spawn no longer leaves child processes unreaped.
- Closed agent sessions stay listed under their worktree.
