# Uiua

[Uiua](https://www.uiua.org/) là ngôn ngữ lập trình đa dụng, dựa trên stack, hướng mảng, đề cao sự đơn giản, vẻ đẹp và code ngầm định (tacit).

Uiua được hỗ trợ qua [extension Uiua](https://github.com/zed-extensions/uiua).

- Tree-sitter: [shnarazk/tree-sitter-uiua](https://github.com/shnarazk/tree-sitter-uiua)
- Language Server: [uiua-lang/uiua](https://github.com/uiua-lang/uiua/)
