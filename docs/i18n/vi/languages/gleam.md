# Gleam

Hỗ trợ Gleam có qua [extension Gleam](https://github.com/gleam-lang/zed-gleam). Để tìm hiểu về Gleam, xem [tài liệu](https://gleam.run/documentation/) hoặc [tham chiếu `stdlib`](https://hexdocs.pm/gleam_stdlib/). Language server của Gleam có nhiều tính năng như đi tới định nghĩa, tự động import và [nhiều hơn nữa](https://gleam.run/language-server/).

- Tree-sitter: [gleam-lang/tree-sitter-gleam](https://github.com/gleam-lang/tree-sitter-gleam)
- Language Server: [gleam lsp](https://github.com/gleam-lang/gleam/tree/main/compiler-core/src/language_server)
