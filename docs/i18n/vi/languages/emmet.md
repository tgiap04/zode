# Emmet

Hỗ trợ Emmet có sẵn qua [extension Emmet](https://github.com/zed-extensions/emmet).

[Emmet](https://emmet.io/) là bộ công cụ cho lập trình viên web, giúp quy trình làm việc với HTML & CSS nhanh hơn nhiều.

- Language Server: [olrtg/emmet-language-server](https://github.com/olrtg/emmet-language-server)
