# ReStructuredText (rst)

Hỗ trợ ngôn ngữ ReStructuredText trong Zode do cộng đồng duy trì qua [extension reST](https://github.com/elmarco/zed-rst).
Báo lỗi tại: [https://github.com/elmarco/zed-rst/issues](https://github.com/elmarco/zed-rst/issues)

- Tree-sitter: [stsewd/tree-sitter-rst.git](https://github.com/stsewd/tree-sitter-rst.git)
- Language Server: [swyddfa/esbonio](https://github.com/swyddfa/esbonio)
