# Yara

Hỗ trợ ngôn ngữ `Yara` trong Zode do [Yara language extension](https://github.com/egibs/yara.zed) cung cấp. Vui lòng báo lỗi tại [https://github.com/egibs/yara.zed/issues](https://github.com/egibs/yara.zed/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language server: [avast/yls](https://github.com/avast/yls)
