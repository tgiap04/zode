# Bảng lệnh (Command Palette)

Bảng lệnh (command palette) là cách chính để gọi các action trong Zode. Phím tắt của nó là một trong những phím đầu tiên nên học: {#kb command_palette::Toggle}.

![Bảng lệnh đang mở](https://zed.dev/img/features/command-palette.jpg)

Để thử, mở bảng lệnh và gõ `new file`. Danh sách lệnh sẽ thu hẹp còn `workspace: new file`. Nhấn Return để tạo một buffer mới.

Mỗi khi hướng dẫn nhắc tới lệnh dạng `zode: ...` hay `editor: ...`, ý là bạn cần chạy lệnh đó trong bảng lệnh.
