# Edge Cases — F010_Debugging

| Scenario                                                                                 | What Happens                                                                                                                  | User-Facing Message                                                                                                               |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Debug adapter binary is missing or misconfigured when starting a session                 | Session start fails before any debugger panes become active; no `DebugSession` is created                                     | "The debugger couldn't start — check that the debug adapter for this launch configuration is installed and configured correctly." |
| Debug adapter rejects a variable edit (e.g. read-only binding)                           | The variable list keeps showing the original value; the write is not applied                                                  | "This value couldn't be changed — the debugger reported it as read-only or otherwise not editable."                               |
| Remote process list request fails while opening Attach to Process                        | The picker falls back to an empty list rather than blocking or crashing the modal                                             | "No processes could be found on the remote host right now."                                                                       |
| Clearing all breakpoints while a session is running                                      | Every breakpoint across every file is removed immediately; the running session no longer stops at any previously-set location | "All breakpoints cleared."                                                                                                        |
| A debug session is active while its project would otherwise be hibernated for being idle | Hibernation is deferred and retried later instead of tearing the project down mid-session                                     | "None — silent handling; the project simply stays fully active until the session ends."                                           |
| Stepping (`StepBack`) is requested but the adapter doesn't support reverse execution     | The step-back control is not available/wired up for that session                                                              | "Step Back isn't available for this debugger."                                                                                    |
