# Edge Cases — F012_ExtensionSystem

| Scenario                                                                                                                          | What Happens                                                                                                                                                     | User-Facing Message                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Extension requests a process/command/download/package it never declared in its manifest                                           | The request is rejected before anything runs — no process spawns, no fetch happens, no install starts                                                            | "None — the extension call simply returns an error to the extension's own code; there is no user-visible dialog for this deny"                             |
| Extension's request is declared in its own manifest but the local user hasn't separately granted it in settings                   | Rejected the same way as an undeclared request — both the manifest AND the local grant must agree                                                                | "None — silent handling at the extension-call level, same as an undeclared capability"                                                                     |
| "Install Dev Extension" is pointed at a folder whose target install path already holds a real (non-symlinked) extension directory | Installation is aborted rather than silently overwriting existing installed content                                                                              | "Extension is still installed" (surfaced as an install error)                                                                                              |
| Rebuilding a dev extension fails to compile                                                                                       | The stale build is NOT silently kept running as if nothing happened — the compile error is logged and surfaced, and the in-progress marker is cleared either way | "None — surfaced via the standard background-task error log path, not a blocking dialog"                                                                   |
| Reloading all extensions while one extension fails to reload                                                                      | That one extension's failure is reported without crashing the extension host or blocking the other extensions from reloading successfully                        | "None — per-extension error, does not interrupt the overall reload"                                                                                        |
| A context server's connection drops mid-session                                                                                   | Status view shows the server has failed/stopped; developer can trigger "Restart" to reconnect                                                                    | "Server disconnected — click Restart to reconnect" (conceptual; wording driven by the status view, not confirmed verbatim from this pass's source reading) |
| A dismissed extension suggestion is later relevant again (e.g. the user opens the same file type on a new project)                | The dismissal is remembered permanently (persisted key-value marker) — the banner will not reappear for that language                                            | "None — the banner simply does not show again"                                                                                                             |
